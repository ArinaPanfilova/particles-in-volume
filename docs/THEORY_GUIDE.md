# Теория к защите: что показывает демонстрация и как это объяснить

Шпаргалка для подготовки. В каждом разделе: суть своими словами → формулы → что показать в программе.
В конце — вопросы, которые вероятнее всего зададут, с ответами.
Полный текст теории для зрителей — в самой программе («Теоретическая часть»), здесь — то, что
нужно знать нам, чтобы уверенно отвечать.

---

## 1. Что именно моделируется

- **Двумерный газ** из N твёрдых дисков радиуса r в прямоугольном сосуде W × H (H = 400, W — ползунок,
  по умолчанию 600). «Объём» везде — площадь: задачи пособия про объёмы, в 2D формулы те же.
- Молекулы летят прямолинейно, **упруго** сталкиваются друг с другом и со стенками
  (молекулярная динамика, `sim.py`). Никакой случайности «вручную» в движении нет: случайность
  появляется из хаотичности столкновений.
- **Температура** — ползунок u: среднеквадратичная проекция скорости. По равнораспределению
  m⟨v_x²⟩/2 = kT/2 на каждую степень свободы, т. е. kT = m·u² (масса молекулы m ∝ r²). Программа держит кинетическую энергию постоянной
  (**термостат**: после каждого кадра скорости слегка масштабируются) — это сосуд в контакте
  с термостатом при постоянной T.
- **Единицы условные**: длина — в единицах, где высота сосуда 400; время — в единицах, за которые
  молекула со скоростью 1 пролетает единицу длины. Нам важны только отношения.
- **Отсчёты**: раз в 2 единицы времени программа записывает n — число молекул в выделенной области.
  Из отсчётов строятся гистограмма P(n), график n(t), среднее и дисперсия «опыта».

**Что показать:** просто запустить любой опыт; закрашенные молекулы — внутри области, полые — снаружи.

## 2. Одна молекула: распределение Бернулли

В равновесии молекула с равной вероятностью может оказаться в любой точке сосуда (равномерное
распределение по координатам — следствие равновесия, эргодичности). Поэтому вероятность быть в области

    p = v / V,   q = 1 − p.

Величина «1, если молекула внутри, 0 — если снаружи» распределена по Бернулли:
⟨n₁⟩ = p, σ² = p(1 − p).

**Тонкость (её часто спрашивают):** в программе p = 0.1992, а не 0.2. Центр диска не может подойти
к стенке ближе, чем на r, поэтому считаем **доступную центрам площадь**. Для полосы у стенки:
p = (a − r)/(W − 2r), где a — ширина полосы. Функция `p_for_radius` в `sim.py`.

**Что показать:** галочка «Выделить одну молекулу» (красная, «Самая-Самая»). Строка «Доля времени
выделенной молекулы в объёме» → стремится к p. Это **эргодичность**: среднее по времени для одной
молекулы = среднее по ансамблю.

## 3. N молекул: биномиальное распределение

Идеальный газ — молекулы не взаимодействуют → попадания разных молекул в область **независимы**.
n = сумма N независимых бернуллиевских величин:

    P_N(n) = C_N^n · pⁿ (1 − p)^(N−n),   C_N^n = N! / (n!(N − n)!)
    ⟨n⟩ = Np,   σ² = Np(1 − p),   σ/⟨n⟩ = √((1 − p)/(Np)).

Вывод одной строкой: среднее суммы = сумма средних (Np); дисперсия суммы **независимых** = сумма
дисперсий (N·p(1 − p)).

**Главная мысль:** относительная флуктуация ∝ 1/√N. При N ~ 10²³ она ~ 10⁻¹² — поэтому
макроскопическая плотность газа «не флуктуирует», хотя для 20 молекул флуктуации огромные.

**Задача 2.15 («во сколько раз»):** удвоили N → ⟨n⟩ и σ² удвоились, σ/⟨n⟩ уменьшилась в √2 раз.

**Что показать:** опыт «Биномиальное распределение» (N = 20, половина сосуда): столбики гистограммы
ложатся на красную кривую. Строки «Среднее» и «Дисперсия»: опыт ↔ теория.

## 4. Предел Пуассона (малая область в большом сосуде)

Если N → ∞, p → 0, а Np = λ = const, то (через второй замечательный предел (1 − λ/N)^N → e^(−λ)):

    P(n) = λⁿ e^(−λ) / n!,   ⟨n⟩ = σ² = λ = n₀·v,   n₀ = N/V — концентрация.

Однопараметрическое: зависит только от концентрации и размера области, **не от размера сосуда**
(задача 2.16). Признак Пуассона: среднее = дисперсия.

**Задача 3.3 — «отражённый» Пуассон:** если область почти весь сосуд (p → 1), то мало молекул
**снаружи**: m = N − n распределено по Пуассону с λ = N(1 − p). Сам n при этом не пуассоновский,
хотя n ≫ 1 — пример того, что «много частиц» ещё не значит «можно Гаусс».

**Что показать:** опыт «Предел Пуассона» (N = 300, v/V = 0.02) — бином и Пуассон совпадают;
опыт «Задача 3.3» (v/V = 0.95) — кривая «Пуассон для N − n».

## 5. Предел Гаусса и «дискретное ↔ непрерывное» (раздел 5а в программе)

При σ² = Np(1 − p) ≫ 1 бином переходит в нормальное распределение:

    P(n) ≈ 1/√(2πσ²) · exp[−(n − Np)²/(2σ²)].

Почему можно сравнивать дискретное P(n) с непрерывной плотностью f(x): вероятность целого n —
это интеграл плотности по ячейке [n − ½, n + ½] ≈ f(n)·1. Это верно, если плотность почти
не меняется на ширине ячейки, т. е. **σ ≫ 1**. Ошибка в середине ~ |1 − 2p|/σ, на «хвостах» больше;
кривая Гаусса к тому же «залезает» в n < 0, если ⟨n⟩ < 2–3σ.

Обратная замена (непрерывное → дискретное) — любая гистограмма непрерывной величины: ячейки
Δx ≪ масштаба изменения плотности, но в каждой ячейке достаточно наблюдений. В нашей модели:
координаты непрерывны, а мы храним один бит «внутри/снаружи»; время непрерывно, а n(t) пишем
через равные промежутки.

**Что показать:** «Несколько молекул» (N = 6, σ ≈ 1) + галочка «Гаусс» — плохо;
«Закрашенная область в углу» (N = 60, σ ≈ 3) — хорошо. Меню «Вид → Гистограмма → по отклонению
от ⟨n⟩»: зелёные столбики (|n − ⟨n⟩| ≤ σ) — примерно 68 % отсчётов, жёлтые (до 2σ) — ещё ~27 %.

## 6. Время: дискретный марковский процесс

**Одна молекула** то внутри, то снаружи — «телеграфный сигнал». Если за время пребывания она
много раз сталкивается и «забывает» прошлое, вероятности переходов в единицу времени постоянны:
γ₋ = 1/⟨t₁⟩ (выход), γ₊ = 1/⟨t₂⟩ (вход), и

    p = ⟨t₁⟩ / (⟨t₁⟩ + ⟨t₂⟩) = γ₊ / (γ₊ + γ₋).

**Число молекул n** — процесс рождения–гибели: n → n + 1 с интенсивностью (N − n)γ₊,
n → n − 1 с интенсивностью nγ₋. Основное кинетическое уравнение (master equation):

    dPₙ/dt = (N − n + 1)γ₊Pₙ₋₁ + (n + 1)γ₋Pₙ₊₁ − [(N − n)γ₊ + nγ₋]Pₙ.

- **Стационарное решение — бином.** Детальное равновесие: Pₙ(N − n)γ₊ = Pₙ₊₁(n + 1)γ₋ →
  Pₙ₊₁/Pₙ = (N − n)/(n + 1) · γ₊/γ₋ — это отношение соседних членов бинома с p = γ₊/(γ₊ + γ₋).
- **Релаксация среднего:** d⟨n⟩/dt = (N − ⟨n⟩)γ₊ − ⟨n⟩γ₋ →
  ⟨n⟩(t) = Np + (n(0) − Np)·e^(−t/τ), 1/τ = γ₊ + γ₋.

**Что показать:** «Начальное состояние → все снаружи объёма» (или опыт «Заполнение через
отверстие»): n(t) экспоненциально выходит на Np. Кнопка «⟳ 90°» — повёрнутая гистограмма стоит
рядом с n(t) на одной шкале: **гистограмма — это доля времени, которое n(t) проводит на каждом
уровне** (эргодичность: среднее по времени = среднее по ансамблю).

**Важная практическая тонкость:** соседние отсчёты n(t) сильно связаны (n меняется медленно,
за время ~τ). Поэтому «Число выборок» больше числа **независимых** измерений,
N_эфф ≈ (полное время)/(2τ), и на коротком прогоне дисперсия опыта может отличаться от теории
на десятки процентов. Ответ на «почему не совпадает»: «дайте поработать дольше» — и показать,
как сближаются цифры.

## 7. Перегородка с отверстием

Область отделена стенкой с отверстием длины c. Поток молекул через отверстие в 2D

    J = n_s ⟨|v|⟩ c / π   (n_s — концентрация, ⟨|v|⟩ ∝ √T).

Меньше отверстие или ниже температура → медленнее обмен → больше τ, n(t) «ленивее».
**Равновесное распределение при этом не меняется** (бином с тем же p): отверстие влияет на
кинетику, но не на равновесие. Если отверстие меньше диаметра молекулы — обмена нет, n = const,
распределение — один столбик (δ-функция), программа пишет об этом на сосуде.

## 8. Конечный размер молекул, примесь, двухатомные молекулы

- **Исключённый объём.** Диски не перекрываются → молекулам «тесно» → появляются корреляции:
  если в области уже много молекул, новой труднее туда попасть. Флуктуации **меньше**
  биномиальных: фактор F = σ²/(Np(1 − p)) < 1. Измерено в модели (N = 300, r = 4, v/V = 0.3):
  F ≈ 0.73, теория (Ван-дер-Ваальс, только отталкивание) — 0.76. Опыт «Плотный газ».
- **Примесь** крупных молекул занимает часть площади и «толкается» с основными; можно считать
  молекулы каждой компоненты отдельно («Считать в объёме»).
- **Двухатомные молекулы** (задача 2.14). Атомы входят и выходят парами: число молекул k
  в области — бином(N/2, p), число атомов n ≈ 2k ⇒ ⟨n⟩ = Np (не изменилось),
  σ² ≈ 4·(N/2)·p(1 − p) = 2Np(1 − p) (**удвоилась**). На гистограмме преобладают чётные n
  (нечётные — когда молекула «сидит» на границе).
- **Форма области не важна** — только p (полоса у стенки или угол).
- **Больше сосуд при той же области** → p меньше → ⟨n⟩ меньше, относительная флуктуация больше.

## 9. Газ Ван-дер-Ваальса (раздел 9а в программе)

Ван-дер-Ваальс добавляет к идеальному газу две поправки: **b** — исключённый объём (у нас уже есть:
твёрдые диски) и **a** — притяжение (ползунок «Притяжение ε / kT₀»). В модели — потенциальная яма
глубины ε у касания, плавно исчезающая на расстоянии двух диаметров между центрами.
ε задано в единицах kT при температуре 2.0; при другой температуре ε/kT = (ε/kT₀)·(2/u)².

Уравнение состояния (2D, n — молекул на единицу площади):

    (P + a n²)(1 − b n) = n kT,   b = 2πr²,   a = −π ∫ U(ρ) ρ dρ.

**Ключевая формула — связь флуктуаций со сжимаемостью:**

    F = σ² / (Np(1 − p)) = kT (∂n/∂P)_T = 1 / [1/(1 − bn)² − 2an/kT].

Смысл: чем легче газ сжать, тем сильнее флуктуирует число частиц. Идеальный газ F = 1;
отталкивание (b) уменьшает F; притяжение (a) увеличивает F. Знаменатель = 0 ⇔ (∂P/∂n)_T = 0 —
**спинодаль**: однородный газ неустойчив, распадается на капли и разреженный газ
(конденсация). У критической точки флуктуации плотности огромны — **критическая опалесценция**.
Критическая точка Ван-дер-Ваальса: n_c = 1/(3b), kT_c = 8a/(27b).

Измерено в модели (N = 300, r = 4, v/V = 0.3):

| ε/kT₀ | F опыт | F теория |
|---|---|---|
| 0 | 0.73 | 0.76 |
| 1.0 | ≈ 1.0–1.2 | 1.04 |
| ≥ 1.5 | сотни (капли) | 1.3–2.7 |

**Почему теория ошибается у перехода:** Ван-дер-Ваальс — **приближение среднего поля**: каждая
молекула чувствует усреднённое притяжение всех остальных, флуктуации плотности не учитываются.
А у перехода именно флуктуации (молекулы собираются в группы) главное — поэтому в модели газ
расслаивается раньше, чем предсказывает формула.

**Что показать:** опыт «Газ Ван-дер-Ваальса» → строка «F = σ²/σ²(бином)», опыт и теория;
притяжение → 0 — F < 1. Опыт «Конденсация» — газ собирается в каплю, капля блуждает,
n(t) скачет между 0 и N, гистограмма двугорбая, F — сотни. Понизить температуру — капли
появляются быстрее (растёт ε/kT).

**Предупреждение:** F опыта надёжен только после нескольких минут работы (см. раздел 6 про
коррелированные отсчёты) — короткий прогон может дать 0.7 или 1.5 при теории 1.

## 10. Связь с курсом статистической физики

(Сверить с списком тем лекций К. С. Григорьева и подписать номера лекций.)

- **Распределения дискретных случайных величин:** Бернулли, бином, Пуассон, их предельные переходы;
  закон больших чисел (σ/⟨n⟩ → 0), центральная предельная теорема (переход к Гауссу).
- **Ансамбли Гиббса:** малая область в большом сосуде — подсистема, обменивающаяся частицами
  с «резервуаром», т. е. большой канонический ансамбль; формула флуктуаций
  ⟨ΔN²⟩ = kT(∂⟨N⟩/∂μ)_{T,V} ⇒ ⟨ΔN²⟩/⟨N⟩ = kT(∂n/∂P)_T (через сжимаемость).
- **Эргодическая гипотеза:** доля времени выделенной молекулы → p; гистограмма по времени =
  распределение по ансамблю.
- **Марковские процессы, кинетическое уравнение, детальное равновесие, релаксация.**
- **Неидеальный газ:** исключённый объём, уравнение Ван-дер-Ваальса, фазовый переход газ–жидкость,
  флуктуации вблизи критической точки, ограниченность теории среднего поля.

## 11. Вопросы, которые вероятно зададут

**Почему опыт не совпадает с теорией?**
Конечное время наблюдения: отсчёты n(t) коррелированы, независимых измерений гораздо меньше,
чем «Число выборок». Дать поработать — цифры сходятся. Систематически отличается только
у плотного газа и с притяжением — там бином и не должен работать (F ≠ 1).

**Почему p = 0.1992, а не 0.2?**
Центр диска не подходит к стенкам ближе r — считаем доступную площадь.

**Что такое «Самая-Самая»?**
Выделенная молекула из задачи 2.13; доля времени, проведённого ею в области, → p (эргодичность).

**Зависит ли распределение от формы области? От размера сосуда?**
Для идеального газа — только через p = v/V. Форма — нет. Пуассон (v ≪ V) — даже от V не зависит,
только от концентрации и v.

**Когда можно перейти к Гауссу? А когда к Пуассону?**
Гаусс: σ² = Np(1 − p) ≫ 1. Пуассон: N ≫ 1, p ≪ 1 при конечном Np. Если p → 1 — Пуассон для N − n.

**Почему при n ≫ 1 в задаче 3.3 нельзя Гаусс?**
Важна не величина n, а ширина распределения: σ² = Np(1 − p) мала, если 1 − p мало.

**Почему у двухатомных дисперсия удваивается, а среднее нет?**
Входят парами: k ~ бином(N/2, p), n = 2k ⇒ D(2k) = 4D(k) = 2Np(1 − p).

**Что будет, если закрыть отверстие? Если сделать его маленьким?**
Закрыть — n не меняется, распределение — один столбик. Маленькое — обмен медленный (большое τ),
но равновесное распределение то же.

**Почему n(t) при старте «все снаружи» растёт по экспоненте?**
Уравнение для среднего линейное: d⟨n⟩/dt = (N − ⟨n⟩)γ₊ − ⟨n⟩γ₋ ⇒ экспонента с 1/τ = γ₊ + γ₋.

**Почему стационарное распределение марковского процесса — бином?**
Детальное равновесие даёт отношение Pₙ₊₁/Pₙ, совпадающее с биномиальным.

**Что показывает повёрнутая гистограмма?**
Сколько времени n(t) проводит на каждом уровне; рядом с n(t) на одной шкале это и видно.

**Что такое F? Почему у плотного газа F < 1, а с притяжением F > 1?**
F = σ²/σ²(бином) = kT(∂n/∂P)_T. Отталкивание: «тесно», газ труднее сжать → меньше флуктуации.
Притяжение: молекулы ходят группами, газ легче сжать → больше флуктуации.

**Почему теория Ван-дер-Ваальса не описывает «Конденсацию»?**
Это приближение среднего поля, оно пренебрегает флуктуациями плотности; у перехода они главные.

**Что такое температура в программе? Зачем термостат?**
u — среднеквадратичная проекция скорости, kT = m·u². Численное интегрирование слегка
нарушает сохранение энергии; термостат возвращает кинетическую энергию — сосуд при постоянной T.

**Почему двумерная модель?**
В задачах фигурируют отношения объёмов, в 2D — отношения площадей; формулы те же, а картинка
нагляднее и считается быстрее.

**Почему «68 % внутри σ» выполняется не всегда?**
Это свойство Гаусса; при σ ~ 1 распределение сильно дискретное и правило работает грубо.

**Что изменится, если удвоить N? Поднять температуру?**
N × 2 → ⟨n⟩ и σ² × 2, σ/⟨n⟩ / √2. Температура не меняет равновесное распределение идеального газа,
только скорость обмена (τ меньше); с притяжением — ε/kT падает, F уменьшается, капли растворяются.
