# Карта кода: где что менять

Шпаргалка к встрече с преподавателем, где мы вживую меняем программу.
Номера строк не указаны: они «уезжают» при правках. Ищите по имени функции или по строке
из примера (Ctrl+F в редакторе, или `Ctrl+Shift+F` — поиск по всем файлам в VS Code).

## 0. Перед встречей и во время неё

```
.venv\Scripts\activate             # один раз в новом терминале
python python_app/app.py           # запуск из исходников — 2 секунды, exe не нужен
python python_app/app.py --demo corner   # сразу открыть готовый опыт
```

Цикл правки: **поменяли → сохранили → закрыли окно → снова `python python_app/app.py`**.

Если стало хуже и надо вернуть как было:

```
git diff                            # что изменено с последнего коммита
git checkout -- python_app/app.py   # вернуть один файл к последнему коммиту
git stash                           # убрать все правки «в карман» (вернуть: git stash pop)
```

Если программа не запускается — ошибка печатается в терминале, последняя строка говорит,
в каком файле и строке. Чаще всего это пропущенная запятая или скобка.

## 1. Как устроена программа

| Файл | Что внутри |
|---|---|
| `python_app/app.py` | окно и все экраны: меню, демонстрация, теория, авторы; кнопки, ползунки, главный цикл |
| `python_app/sim.py` | физика: молекулы, столкновения, притяжение, стенки, статистика, формулы распределений |
| `python_app/charts.py` | рисование гистограммы P(n) и графика n(t) |
| `python_app/palette.py` | **все цвета** сосуда и графиков (три схемы) |
| `python_app/fonts.py` | **все шрифты**; общий размер текста `DEFAULT` |
| `python_app/i18n.py` | **все тексты** на трёх языках и теория |
| `python_app/htmlview.py` | показ теории (простая HTML-разметка, дроби) |
| `python_app/assets/` | фото авторов и эмблемы |

Как работает демонстрация (`app.py`, функция `loop`): каждые ~16 мс (≈ 60 раз в секунду)

1. `self.sim.advance(...)` — модель продвигается во времени (физика в `sim.py`, функция `step`);
2. `draw_vessel()` — рисуется сосуд (класс `VesselView`, функция `draw`);
3. каждый 3-й кадр — `draw_charts()` (гистограмма и n(t), файл `charts.py`);
4. каждый 6-й кадр — `update_stats()` (таблица «Статистика»).

Модель раз в `sample_dt = 2.0` единицы времени записывает отсчёт n (функция `sample` в `sim.py`) —
из этих отсчётов строятся гистограмма, n(t) и средние.

## 2. Рецепты: «поменяйте, пожалуйста, …»

### Диапазон или шаг ползунка

`app.py`, функция `_build_side`. Каждая строка — один ползунок:

```python
self._slider(p, 'N', 'N', 1, 500, 1, reinit=True, fmt='%d')
#               имя  текст  мин макс шаг   перезапуск  формат числа
```

Например, «число молекул до 1000» → поменять `500` на `1000`.
`fmt='%.1f'` — один знак после запятой, `'%d'` — целое.

### Значения по умолчанию (с чего начинается демонстрация)

- `app.py`, словарь `BASE` — параметры, которые ставятся перед каждым готовым опытом;
- `sim.py`, словарь `self.p` в `Simulation.__init__` — параметры при самом первом запуске
  (там же комментарий к каждому параметру).

### Готовые опыты

`app.py`, список `PRESETS`. Одна строка — один опыт:

```python
('corner', 'presetCorner', dict(N=60, r=4, frac=0.2, shape='corner'), dict(binom=True, gauss=True), 3),
#  id       ключ текста     параметры модели (поверх BASE)           какие кривые показать        скорость
```

Название опыта — в `i18n.py` по ключу (`'presetCorner': ...`) на каждом языке.
Новый опыт = новая строка здесь + новый ключ в трёх словарях `i18n.py`.

### Что открывается при запуске программы

`app.py`, в `App.__init__` строка `self.go('menu')`. Например, сразу демонстрация с опытом:

```python
self.go('demo')
idx = [p[0] for p in PRESETS].index('corner') + 1
self.preset_cb.current(idx)
self.apply_preset(idx)
```

(вставить вместо `self.go('menu')`; так же это делает `main()` для ключа `--demo`).

### Размер текста

- **Весь текст сразу:** `fonts.py`, `DEFAULT = 1.3` (1.0 — обычный, 1.5 — крупнее).
  Во время показа то же самое: «Вид → крупнее/мельче» или Ctrl + / Ctrl −.
- **Цифры на осях графиков:** `charts.py`, `TICK = 11`.
- **Отдельная надпись:** найти её `fonts.font(11, 'bold')` и поменять число
  (это размер в пунктах до общего множителя). Заголовки панелей — 11, подписи ползунков — 9,
  кнопки — 10, теория — 12 (`htmlview.py`).
- **Страница авторов:** `app.py`, `draw_authors`: `font(0.036)` — доля размера окна.

### Цвета

- **Сосуд и графики:** `palette.py`. Три схемы: `'color'` (обычная), `'contrast'`, `'bw'`.
  Ключи: `region` — закрашенная область, `mol` — молекулы, `bar` — столбики гистограммы,
  `binom` / `pois` / `gauss` — кривые, `band` — полоса ⟨n⟩ ± σ, `lw` — толщина линий.
  Цвета — в формате `'#rrggbb'` (можно взять в любом «color picker»).
- **Фон окна, панели, кнопки:** `app.py`, константы в начале: `BG` (фон), `PANEL` (панели),
  `ACCENT` (синие кнопки и заголовки), `INK` (текст), `MUTED` (серый текст).
- **Какая схема при запуске:** `palette.py`, строка `C = dict(PALETTES['color'])`.

### Расположение на экране

- **Сосуд крупнее, графики меньше (или наоборот):** `app.py`, константы
  `VESSEL_SHARE, CHARTS_SHARE = 1, 1` — доли высоты. Например, `3, 2`.
- **Ширина панели параметров:** `app.py`, функция `_side_w`: `self.px(380)` — ширина,
  `0.34` — не больше трети окна. Панель можно скрыть кнопкой «Скрыть панель».
- **Порядок разделов панели:** `app.py`, `_build_side` — разделы идут в том порядке,
  в каком вызываются `self._panel(...)`; можно переставлять блоки целиком.
- **Кнопки верхней полосы:** `app.py`, `_build_demo`, строки `.pack(side='right')` —
  упаковываются справа налево (первая в коде — самая правая).

### Тексты и подписи

`i18n.py`: три словаря `ru = {...}`, `en = {...}`, `zh = {...}` с одинаковыми ключами.
Найти нужный текст: поиск по самой фразе, например «Число молекул». Если ключа нет
в `en`/`zh`, показывается русский вариант.

### Теория

`i18n.py`, ключ `theoryHtml` (разделы 1–10) и отдельные ключи `theoryExtra` (11),
`theoryDiscrete` (5а), `theoryVdw` (9а), `theoryRefs` (литература). Разметка:
`<h2>` — заголовок, `<p>` — абзац, `<i>`/`<b>` — курсив/жирный, `<sub>`/`<sup>` — индекс/степень,
`<div class="eq">` — отдельная формула, `F('числитель', 'знаменатель')` — дробь «этажом».
Порядок вставки разделов и оглавление — `app.py`, функция `_theory_html`.

### Скорость моделирования, частота кадров

- ползунок «Скорость моделирования» — множитель `sim_speed`;
- `app.py`, `loop`: `self.after(... 16 ...)` — пауза между кадрами в мс;
  `frame_no % 3`, `% 6` — как часто перерисовываются графики и статистика;
- `sim.py`: `sample_dt = 2.0` — как часто записывается отсчёт n.

### График n(t)

`charts.py`: `WIN = 1500` — сколько последних отсчётов видно на масштабе 1:1;
`ZOOMS = 4` — число уровней масштаба; `3.5 * sig` в `series_range` — какой коридор n
показан на масштабе 1:1.

### Гистограмма

`charts.py`, функция `hist`: `4.5 * sig` — какой диапазон n показывать;
`0.8` в `bw = ... * 0.8` — ширина столбика (доля шага); раскраска по σ — `sig1/sig2/sig3`
в `palette.py`.

### Физика

`sim.py`:

- `H = 400.0` — высота сосуда (ширина — ползунок W);
- `LAM = 2.0` — радиус притяжения (в диаметрах); `U0` — температура, в единицах которой задано ε;
- `collide` — упругие столкновения дисков; `attract` — притяжение; `step` — один шаг: движение,
  силы, столкновения, стенки, перегородка; `advance` — много шагов + термостат;
- `p_for_radius` — теоретическое p с учётом того, что центр диска не подходит к стенке ближе r;
- `vdw_factor` — теоретический фактор F по Ван-дер-Ваальсу.

### Страница авторов

`app.py`, `draw_authors`: `lg, ph = u * 0.14, u * 0.47` — высота эмблем и фото;
`W * (0.3 if k == 0 else 0.7)` — где по горизонтали стоят фото. Фото — файлы в `assets/`.
