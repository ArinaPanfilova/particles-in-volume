# Частицы в выделенном объёме / Particles in a Selected Volume

Интерактивная демонстрация к задачам 1.10–1.12, 2.13–2.16, 2.23, 3.3 из пособия
О. А. Чичигиной «Вероятностные распределения физических величин. Сборник задач» (МГУ, 2026).

Авторы: Кирсберг Арина Павловна, Черяпина Анна Сергеевна (факультет ВМК МГУ).
Руководитель: О. А. Чичигина (физический факультет МГУ).

## Запуск (для пользователя)

Скачайте `ParticlesInVolume.exe` со страницы **Releases** этого репозитория и запустите двойным щелчком
(Windows 10/11). Установка Python, библиотек и интернет не нужны: exe полностью автономен,
рядом с ним не должно лежать никаких других файлов.

Ключи командной строки: `ParticlesInVolume.exe --theory`, `--authors`, `--demo <опыт>`
(сразу открыть готовый опыт: `few`, `p112`, `corner`, `binom`, `poisson`, `bigV`, `p33`,
`hole`, `dense`, `bigAtoms`, `diatomic`, `imp`).

## Разработка

Один раз после клонирования:

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Дальше:

```
python python_app/app.py          # запустить программу из исходников (быстро, для правок)
python python_app/build_exe.py    # собрать python_app/dist/ParticlesInVolume.exe (~1 мин)
```

Порядок работы: правим код → проверяем через `app.py` → коммитим → перед показом собираем exe
и выкладываем его в новый Release на GitHub (Releases → Draft a new release → прикрепить exe).
Сам exe в git не хранится (см. `.gitignore`).

## Возможности

- Главное меню: «Демонстрация», «Теоретическая часть», «Авторы», «Язык» (русский / English / 中文).
- Двумерный газ из твёрдых дисков с упругими столкновениями; выделенная область закрашена,
  молекулы внутри неё закрашены, снаружи — полые.
- Выделенная область — полоса у стенки или прямоугольник в углу сосуда (как на рисунке к задаче).
- Параметры: число и радиус молекул, температура, размер сосуда V (при неизменной области v),
  доля объёма v/V, непроницаемая перегородка с отверстием переменного размера, примесь
  молекул другого размера, объединение атомов в двухатомные молекулы, начальное состояние.
- Гистограмма P(n) в сравнении с биномиальным, пуассоновским и гауссовским распределениями.
- Временная динамика n(t) с теоретическим ⟨n⟩ ± σ, выделенная молекула («Самая-Самая»).
- 12 готовых опытов к задачам пособия.
