## Интерфейс

- [ ] Кнопки и подписи в демонстрации, на титульном листе и на странице авторов двуязычные
      (сейчас есть переключатель ru / en / 中文; уточнить, достаточно ли этого).
- [ ] При запуске сразу открывается самый интересный опыт.
- [ ] Всё как можно крупнее и понятнее: шрифты, цвета. Понятность важнее эстетики.
- [ ] Проверить на разрешениях проектора (1024×768, 1280×720, 1366×768, 1920×1080) и при масштабе
      Windows 100–150 %.
- [x] Панель параметров прокручивается колёсиком над любым её элементом (Windows, macOS, Linux),
      сосуд и графики остаются на месте.
- [x] Меню «Цвета»: раскраска молекул (в области / по скорости / по начальному положению),
      гистограммы (одним цветом / по σ), схемы: цветная, контрастная, чёрно-белая. Цвета — в `palette.py`.
- [ ] macOS / Linux: шрифтов Segoe UI и Consolas там нет, Tk подставит другие, вёрстка
      может поплыть. Проверить там же, что видны китайские символы.
- [ ] Проверить на очень простом компьютере. Сборка на Python 3.14 работает только на Windows 10/11;
      если показ на Windows 7/8, собирать exe на Python 3.8.

## Подготовка к часовой правке кода вместе с преподавателем

Оба автора должны уметь быстро менять:

- диапазоны и значения по умолчанию параметров (слайдеры, `PRESETS` в `app.py`);
- размеры шрифтов, цвета, расположение элементов на экране (`app.py`, `charts.py`);
- тексты (`i18n.py`).

Перед встречей: оба запускают программу из исходников (`python python_app/app.py`), и у обоих
работает `git`, чтобы откатывать неудачные правки (`git diff`, `git checkout -- <файл>`).
